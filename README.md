# SiteSearch — Search Within Any Website

Search within any website using Google, Bing, or DuckDuckGo's `site:` operator. One click from the toolbar, type your query, and get results from just the current site.

## Features

- **Site-Scoped Search**: Automatically detects the current site and searches only within it
- **Multi-Engine Support**: Choose between Google, Bing, or DuckDuckGo
- **Search History**: Keeps your last 8 site searches for quick re-access
- **Keyboard Shortcut**: Alt+S to open instantly
- **Clean Dark UI**: Minimal, distraction-free interface
- **Zero Permissions**: Only needs access to the active tab to detect the domain
- **No Tracking, No API Keys**: Everything runs locally in your browser

## How It Works

1. Navigate to any website
2. Click the SiteSearch icon (or press Alt+S)
3. Type your search query
4. Press Enter — results open in a new tab, scoped to just that site

## Why Use SiteSearch?

Many websites have poor built-in search. Google's `site:` operator is the most powerful way to find content on a specific domain, but typing `site:example.com your query` manually is tedious. SiteSearch automates this in one click.

## Installation

1. Download and extract the extension
2. Go to `chrome://extensions/`
3. Enable "Developer mode" (top right)
4. Click "Load unpacked" and select the `sitesearch` folder

## Privacy

- No data collection
- No external API calls (just redirects to your chosen search engine)
- Search history stored locally in browser storage only
- No analytics or tracking
